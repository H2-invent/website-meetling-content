# Per Telefon an einer Videokonferenz teilnehmen: Einwahlnummer, PIN und typische Hürden

Sie möchten an einer Videokonferenz teilnehmen, haben aber gerade kein stabiles Internet zur Hand? Mit der Meetling-Telefoneinwahl können Sie auch ohne Internetverbindung an der Konferenz teilnehmen. Dafür brauchen Sie vor allem die aktuelle Einladung und ein Telefon.

Dieser Leitfaden zeigt, welche Angaben Sie bereitlegen, wie die Einwahl abläuft und was Sie bei einer nicht akzeptierten PIN oder fehlendem Ton tun können.

## Das brauchen Sie vor der Telefoneinwahl

Öffnen Sie die aktuelle Meeting-Einladung, bevor Sie wählen. Halten Sie bereit:

- die dort angegebene Rufnummer oder Nebenstelle,
- gegebenenfalls eine Konferenzkennung sowie
- eine PIN oder ein Token, falls die Einladung diese Angabe enthält.

Welche Daten abgefragt werden, kann je nach Konferenz unterschiedlich sein. Nutzen Sie deshalb immer die Angaben aus der neuesten Einladung. Die allgemeine Unternehmens-Kontaktnummer ist kein Ersatz für den Konferenzzugang.

Mehr zum Prinzip finden Sie auf der Meetling-Seite zur [Telefoneinwahl für den Zugriff von überall](https://meetling.de/funktionen/teamwork-tools/telefoneinwahl).

## So nehmen Sie per Telefon an der Videokonferenz teil

1. **Nummer aus der Einladung wählen.** Verwenden Sie die Rufnummer oder Nebenstelle genau so, wie sie in der aktuellen Einladung steht.
2. **Ansage und Einladung abgleichen.** Falls eine Ansage Sie zur Eingabe weiterer Zugangsdaten auffordert, folgen Sie ihr.
3. **PIN oder Token eingeben – falls verlangt.** Übernehmen Sie die Angabe genau aus der Einladung. Eine feste PIN-Länge, eine allgemeine Tastenfolge oder einen einheitlichen Eingabezeitpunkt sollten Sie nicht voraussetzen.
4. **Audio prüfen.** Hören Sie nach dem Verbinden kurz, ob Konferenzton anliegt. Stellen Sie sich bei Bedarf vor und prüfen Sie die Stummschaltung Ihres Telefons.

Meetling beschreibt für die hochsichere Telefoneinwahl eine personenbezogene Einwahl per PIN oder Token. Entscheidend ist: Verwenden Sie nur die Daten, die Ihnen für dieses Meeting bereitgestellt wurden. Weitere Informationen dazu finden Sie bei der [hochsicheren Telefoneinwahl](https://meetling.de/funktionen/teamwork-tools/hochsichere-telefoneinwahl).

## Was mit der Telefonverbindung möglich ist – und wofür Sie den Meeting-Link brauchen

Die Telefoneinwahl ist für das Mithören und Sprechen gedacht. Wenn Sie eine Präsentation sehen, im Chat lesen oder schreiben oder Video nutzen möchten, öffnen Sie zusätzlich den Meeting-Link auf einem geeigneten Gerät.

Praktisch ist die Kombination aus Telefon und Browser besonders dann, wenn Sie über das Telefon sprechen möchten, aber auf dem zweiten Gerät Inhalte verfolgen. Aktivieren Sie den Ton dabei nur auf einem Gerät, damit keine Rückkopplung entsteht.

Die browserbasierten Funktionen wie Bildschirmfreigabe und Chat sind auf der [Meetling-Funktionsübersicht](https://meetling.de/funktionen) beschrieben.

## Typische Hürden bei Einwahlnummer und PIN

### Die Einwahlnummer führt nicht zur Konferenz

Vergleichen Sie die Nummer Zeichen für Zeichen mit der neuesten Einladung. Haben Sie mehrere Einladungen erhalten oder stehen dort unterschiedliche Angaben, fragen Sie die organisierende Person nach dem aktuellen Stand.

### Die PIN oder das Token wird nicht akzeptiert

Geben Sie die Angabe erneut genau aus der aktuellen Einladung ein. Ergänzen Sie keine Zeichen aus eigener Annahme. Bleibt der Zugang verwehrt, benötigt die organisierende Person die gültigen Zugangsdaten für diese Konferenz.

### Sie hören nichts oder die Verständlichkeit ist schlecht

Prüfen Sie Lautstärke und Stummschaltung Ihres Telefons. Testen Sie bei Bedarf Headset oder Freisprechen, achten Sie auf den Mobilfunkempfang und verbinden Sie sich erneut. Hält das Problem an, informieren Sie die organisierende Person, damit sie den Ablauf mit Ihnen abstimmen kann.

### Sie brauchen Präsentation, Chat oder Kamera

Öffnen Sie parallel den Meeting-Link auf einem internetfähigen Gerät. Lassen Sie den Ton nur auf dem Telefon oder nur auf dem zweiten Gerät aktiv – nicht auf beiden gleichzeitig.

## Kurz-Checkliste vor dem Anruf

- Neueste Einladung geöffnet?
- Richtige Rufnummer oder Nebenstelle bereit?
- PIN oder Token vorhanden, falls in der Einladung genannt?
- Telefon nicht stummgeschaltet und Empfang ausreichend?
- Meeting-Link auf einem zweiten Gerät geöffnet, falls Sie Inhalte sehen oder Chat nutzen möchten?

Mit diesen fünf Punkten ist die Telefonteilnahme gut vorbereitet. Wenn Angaben fehlen oder nicht zusammenpassen, ist die aktuelle Einladung beziehungsweise die organisierende Person die verlässlichste Quelle.
