Oben rechts auf der Startseite klickt man auf das eigene Profil. Dort auf PERSÖNLICHE EINSTELLUNGEN gehen. Dann kann ein Profilbild über DATEI AUSWÄHLEN und dem anschließenden speichern hochgeladen werden.

Im Profil unter PROFIL BEARBEITEN kann der Vor- und Nachname, sowie die E-Mail Adresse angepasst werden.
