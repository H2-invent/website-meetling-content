Auf der Hauptseite neben KONFERENZ PLANEN auf TERMINUMFRAGE klicken. Ein neues Fenster öffnet sich, in dem alle relevanten Daten für das zukünftige Videomeeting eingetragen werden (Name, Agenda, Dauer der Konferenz). Danach auf SPEICHERN klicken.

Die mit einem Stern gekennzeichneten Felder sind Pflichtfelder.

Nachdem SPEICHERN erscheint ein neues Fenster, indem die Terminoptionen ausgewählt werden. Nach Eingabe aller Terminoptionen oben rechts auf das X zum Schließen klicken.

Die Terminumfrage erscheint nun auf der Startseite von meetling. Um die Terminumfrage an alle betreffenden Teilnehmer zu versenden, klickt man auf TEILNEHMENDE. Dadurch öffnet sich ein neues Fenster. Über TEILNEHMENDE SUCHEN oder E-MAIL ADRESSEN VON NEUEN TEILNEHMENDEN EINGEBEN können nun alle E-Mail Adressen eingegeben werden. Mit klicken auf E-MAIL ZUR EINLADUNG VERSENDEN werden die Teilnehmer automatisch auf die TEILNEHMENDENLISTE gesetzt.
