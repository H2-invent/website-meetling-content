Auf der Startseite auf KONFERENZ PLANEN gehen und die Daten für die Videokonferenz eingeben. Ganz unten in diesem Fenster befindet sich das Feld TEILNEHMENDENLISTE DEAKTIVIEREN, BEITRETEN ÜBER TEILNEHMENDEN-LINK. Dieses aktivieren und SPEICHERN.

Das Feld mit der Teilnehmerliste kann über ABBRECHEN geschlossen werden. Den Link zum Videomeeting findet man rechts bei Klick auf LINK ZUM BEITRETEN. Dieser Link kann kopiert und an die gewünschten Teilnehmer gesendet werden oder zur freien Einschreibung auf einer Website/ Landingpage zur Verfügung gestellt werden.
